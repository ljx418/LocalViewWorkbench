# 模型路由与预算政策

## 默认路由

| 任务 | 默认执行者 |
|---|---|
| PRD、架构、合同、Stage 设计、重大争议、Stage 裁决 | Codex + Sol |
| 中等复杂度、多文件业务实现 | Claude Code + MiniMax |
| 小型实现、批量适配、脚本、夹具、仓库检索 | Claude Code + DeepSeek |
| 编译、类型、合同、固定分母和确定性回归 | 可信执行器 |
| 独立复算和证据检查 | 隔离的 DeepSeek 实例 |
| 复杂假绿、安全或语义争议 | Codex + Sol |
| 产品体验、高风险操作和最终发布 | 人类 |

路由是初始运营参数，不是能力排名。调整路由必须依据“通过独立验收的 Workpack 总成本”和可复现质量数据，不改变职责权限。

## V0 临时路由覆盖

因 Claude Code 当前无可用额度，项目负责人已授权在 V0 结束前由隔离的 Codex 实现实例临时承担 Claude Code + MiniMax 与 Claude Code + DeepSeek/DSH 的实现职责。该覆盖只改变执行载体，不改变权限边界：root Codex 仍是 Stage 门禁负责人；每个 Workpack 仍只有一个实现 owner；实现实例只能提交 `READY_FOR_REVIEW`；同一候选必须由未参与实现的隔离 Codex 审查实例复算，root 再作门禁裁决。额度恢复或 V0 结束时，本覆盖自动失效，后续路由须重新冻结。

## 预算规则

- Sol 建议预留 20%–30% 用于 Stage 收口、复杂审查和裁决；比例可依据指标调整。
- MiniMax 优先使用已有套餐，但不得因额度不足降低测试标准。
- DeepSeek 每个任务必须设调用、输出、工具和重试预算，并分别记录缓存命中与未命中费用。
- 预算耗尽且必要验证未完成时进入 `WAIT_BUDGET`，不得用旧证据、缩分母或降阈值通过。
- 同一失败路线连续两次没有新证据或进展时停止，保存交接并升级；不得无限重试。
- 谷时可用于非关键批量任务，但不能阻塞关键路径。

## 成本口径

```text
合格 Workpack 总成本
= 模型调用费 + 失败重试费 + 复审成本 + 必要人工介入成本
```

同时记录排队时间、执行时间、审查时间、首次验收通过率和返工轮次。任何模型别名都必须在运行前解析为实际 provider/model 并写入收据。
