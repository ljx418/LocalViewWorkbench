# V0-S0 Scope And Non-Goals

## 目标

- 只读核对 Windows、GPU/驱动、内存、ComfyUI/Python、Prompt Assistant、Ollama/model digest、FFmpeg。
- 从真实节点注册表确认图像/视频输入、编辑/展示、取消/卸载和输出类型。
- 用一张获授权图片和一条获授权短视频的四帧请求探测真实调用、限制和资源行为。
- 产出 inventory、node-bindings、reuse-audit 和原始脱敏证据。

## 非目标

- 不修改 ComfyUI、Prompt Assistant、PyTorch、CUDA、模型、工作流或系统配置。
- 不下载依赖/权重，不升级环境，不实现 V0-S1 功能。
- 不以 S0 探测替代 V0-A01/A02/A09/A10 的最终固定分母验收。
- 不读取 Cookie、浏览器 profile、无关媒体或未授权路径。
- 不宣布 V0、硬件质量或性能通过。
