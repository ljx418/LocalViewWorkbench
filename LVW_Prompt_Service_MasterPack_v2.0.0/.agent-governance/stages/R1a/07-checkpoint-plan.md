# R1a Checkpoint Plan

## Gate 1–3：离线

- Python unit/API/合同负例、媒体 exact/one-over。
- TypeScript、React tests/build；提示配置枚举、800 字边界和 dirty draft。
- runtime ownership、同源、loopback、无 CDN/秘密/绝对路径扫描。
- V0 回归、治理校验和候选绑定收据。

## Gate 4：真实验收与独立审查

只在新鲜一次性授权后运行固定 testSource 图片、真实 loopback Ollama 和 headless Chromium。浏览器必须提交 `faithful` 配置与固定自定义指导，确认外部 Ollama 控制禁用；provider 调用恰为 1，失败/清理 fail-closed。独立审查 Fatal=0、Major=0 才能进入人工签署。

## Gate 5：人工体验

人类检查界面、输出、编辑、错误恢复和导出。结论不等于 V1 或发布批准。
