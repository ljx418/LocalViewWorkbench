# 范围
现有React/FastAPI内图片/视频上传、预览、四帧分析、状态、取消、raw/建议/人工稿、TXT/JSON和统一启动。无Comfy依赖、无新帧图片API、无持久SQLite修订、无批处理/MCP/ASR/长片、无下载。11个人工视频不提交模型。

内部修正：一次真Provider观察全部实际源PNG并逐帧描述外观；VideoKernel纯CPU测量单独留原始数值，AnalysisService组合机器建议与局限。无物理运镜/主体连续动作保证，不把注册当语义核验。不改公开合同、不免未来V0-A12/Q01原始质量评分。原tracking仍必须通过受支持的空间变化义务；错误raw不能被组合文字抵消。
