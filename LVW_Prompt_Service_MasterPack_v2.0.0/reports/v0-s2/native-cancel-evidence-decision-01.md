# Native cancellation evidence decision 01

APPROVED_FOR_OFFLINE_IMPLEMENTATION by codex_gate_owner. Packet 1.0.13. No change to public business API/Schema, fixed Stage or cumulative acceptance IDs, thresholds, preparation or full checkpoint budgets. This decision grants no native execution.

The ordinary video owner/interruptible transport may emit bounded native evidence under process-only LVW_NATIVE_CHECKPOINT=run-owned-v1. It is disabled by default and mutually exclusive with the warm measurement profile. A fresh immutable run-owned binding freezes candidate, child authorization SHA, model digest, owned Ollama PID/birth, maximum runs and native-clock lease (at most two hours). Start and provider operations fail closed after expiry; expiry never prohibits owned cleanup. The wrapper clears inherited flags in ordinary mode. The default inference/unload protocol remains unchanged; audit mode adds ownership checks and evidence I/O, and must not be represented as proof of unaudited timing or of browser behavior.

Use the existing production VideoRequestOwner and InterruptibleOllamaTransport, not a replacement inference entry. Reprove the root before connection work, after connection before POST, and before cleanup controls. Charge checks against the existing shared request/control deadline. Count attempts separately from actual sends and exact completed Ollama log prefix deltas. Never retry an expired run token or silently create a new lease. Bound journal size and forbid reparse/config mutation. Preserve hashes and metadata, not source media, request bodies or prompt text in the journal.

Cancellation records its observation under the owner lock; disk/process proof work occurs outside the acknowledgement lock. Retain original native observation time even though its event is written at termination. Distinguish connection closure, acknowledged unload, empty inventory, three stable GPU points and independent sampler confirmation. Connection closure alone is not a model/GPU stop witness. Record the observed stop confirmation and explicitly do not claim an exact CUDA kernel stop timestamp. Require cancellation feedback within one second and physical release within thirty seconds from the cancellation observation (also within the existing release budget); this is stricter evidence, not a relaxed threshold.

The pure cancellation oracle joins candidate/auth/token/native owner/run ordinal, ordered events, actual log prefix hashes/bytes/counts, uniquely indexed sends and owner proofs, raw acknowledgement, empty inventory, shared release deadline, one-second GPU cadence and independent sampler agreement. Test exact limits and one-over. Preparation cancellation must have zero provider delta, zero GPU admission and no publication. Neither oracle result constitutes Stage acceptance. Browser draft protection, final owned-process/temp cleanup, privacy and independent review remain mandatory and must be bound by the future full parent.

Terminal persistence failure revokes results, leaves resources unknown and quarantines the inference slot. Successful results remain unavailable during terminal persistence so a concurrent workbench adoption cannot race a failing journal. Synthetic owner/HTTP/GPU tests prove branches only. No real service, model, browser, GPU or media action was run for this implementation batch.
