# Warm phase coordinator decision 01

APPROVED_FOR_OFFLINE_IMPLEMENTATION by codex_gate_owner. Packet 1.0.7. Implements the existing fixed 10-image/10-four-frame hot phase without changing public contracts, acceptance IDs, denominators, numerical thresholds, Stage checkpoint/recheck budgets or external permissions.

WarmPhase is an internal helper, with no CLI, service startup or self-authorization. A sealed parent must provide owned services/sampler, exact staged sample hashes, candidate/child/model/executable binding, a permission/budget callback, concurrent resource abort monitoring (also during blocking preloads), and terminal service cleanup. No complete live Stage coordinator exists yet. Its caller must not confuse helper availability with native readiness or consume a full checkpoint early.

Before each preload, reprove Ollama PID/birth and model digest. Before billable/new work, obtain the parent's grant and durably charge the action. Use frozen production graph templates through public submit/history. Bind actual provider log counts, same-native-clock intervals, sequential warm event numbers and original artifact hashes. Begin measured time at a new real sampler point; never shift traces or subtract queue/cleanup. Each request uses a fresh public ID; history graph must equal the submitted graph. Failed/unknown calls, cached outputs, changed source bytes and old event streams abort without retry, replacement or denominator shrinkage.

Preload recovery is separately owned and charged. Reprove the bound root before unload; root proof, unload acknowledgement, empty inventory and three fresh stable GPU samples share thirty seconds. New-work refusal/lease expiry cannot block the already reserved cleanup of owned resources. Interruption writes terminal evidence and cleans before propagating. Original raw artifacts remain in the isolated temporary root until the parent applies its retention/redaction policy; user exports are never executor receipts.

Physical release now additionally requires the independent continuous sampler to corroborate at least two observations within the transport's final three-point stable window, at the same existing baseline+1024 MiB threshold. This detects contradictory raw telemetry rather than accepting a model-released flag. The full fixed denominator, binary identity, candidate/child identities and actual provider evidence are still independently joined before a phase-only result. A warm phase result is never Stage PASS, human acceptance or release authorization.
