# Owned-provider fault phase decision 01

APPROVED_FOR_OFFLINE_IMPLEMENTATION by codex_gate_owner; packet 1.0.15. No public API/Schema, Stage/cumulative case IDs, threshold or preparation/full-run budget changes. Four fault subchecks refine existing A10/manual obligations and never replace the Stage denominator. No native target execution is granted by this decision.

Implement a one-shot FaultPhase as the last default-runtime phase: exactly one deliberate stop of the run-owned Ollama root during one active GPU-resident provider request, then CPU manual preview, rejected quarantine re-entry and denied result adoption. Parent must predeclare the process/sampler/action budget, own both services and retain source/fixture/model/child bindings. Require the same pinned Comfy TCP peer for queue/status/history/manual calls and do not reconnect after the final expected workbench 409. Persist and validate the bounded raw 409 body, rather than inferring ATTEMPT_STALE from HTTP status alone. Require matching graph, prompt, token, owner, decoded source hash, real error/no outputs and no publication. A missed active window is NO_GO with no retry or alternate sample. Cancellation now also joins source_prepared to the frozen input hash.

Expected fault outcome is failed/unknown with the shared inference slot quarantined, not successful in-process recovery. After the root dies, inability to prove cleanup through that dead API must not become resource_state=released. Independent parent evidence must separately prove physical release from actual native root/child stops plus whole-GPU sampling. Manual preview remains CPU-only and preserves exact human fields, schema-valid JSON and TXT; quarantine re-entry must return the actual production RESOURCE_BUSY error without new journal/provider work; adoption must return ATTEMPT_STALE without a draft/result. Browser experience is still a separate requirement. Parent proves final cleanup and starts a fresh warm runtime, never clears product quarantine by hand.

Strengthen native stop: pin SafeHandle and compare exact GetProcess.StartTime before Kill. Root stops require actual STOPPED, with observed UTC request/exit-confirmation timestamps; absence/replacement alone cannot prove deliberate fault injection. Snapshot bounded children while the exact root handle is pinned; record parent chain, CIM birth and native birth with sub-microsecond truncation consistency. Stop only these exact original child objects, deepest first after root stop. Already-absent originals or recycled child PIDs are recorded without killing replacements. Preserve snapshots across repeated cleanup. Scan for previously unbound children after stop; report NO_GO rather than guessing their ownership or silently omitting them. Final root/port/wrapper/temp proofs remain mandatory. Windows syntax tests and a PowerShell fake-process execution prove the guarded branches without any real process query or termination; actual native compatibility is NOT_RUN.

Use an explicit sampler transition before the fault: start a fresh Comfy-only-private-process sampler while the ordinary Comfy+Ollama sampler remains alive, then prove the previous sampler terminal and raw time coverage with no gap over 1.5 seconds. Continue whole-GPU and host-RAM sampling through root death. Never read private bytes from a dead/recycled Ollama PID or invent zero. Retain both complete traces, scopes, ownership and handoff points; this fault-only stream cannot substitute for the two-process warm benchmark stream or its measurements. Both sampler starts and their owned nvidia children require the parent's explicit finite action budget. Reject transition in warm/non-audit mode, repeated transition or missing/failed terminal/coverage evidence.

The pure fault oracle requires native event/source identity and owner proof, root/child absence receipts, an interrupted send spanning the actual stop-request UTC observation, native before/after stop clock brackets, original provider prefixes, a failed unpublished terminal and three stable independent GPU points within thirty seconds of the conservative pre-stop bracket. A killed server may not flush its final GIN line; retain zero delta when that is what occurred, and independently prove the interrupted send through the native request/root witnesses. Do not fabricate a completed log entry or an exact GPU-kernel stop timestamp. Normal/warm public call denominators are unchanged.

Still required before real acceptance: complete bounded parent and fresh whole-source offline gate, native decoder compatibility, actual public/browser/manual/cancel/fault and cumulative evidence, fixed 10+10 warm measurements, all owned cleanup/privacy and isolated independent review. Fixture preparation slots remain exhausted; no component or full live checkpoint has been consumed by these offline changes.
