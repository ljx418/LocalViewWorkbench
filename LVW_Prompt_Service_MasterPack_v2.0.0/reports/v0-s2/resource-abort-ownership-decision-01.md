# Concurrent resource abort and native ownership decision 01

APPROVED_FOR_OFFLINE_IMPLEMENTATION by codex_gate_owner. Packet 1.0.8. This refines existing resource-stop, owned-process and failure-evidence obligations. No public API/Schema, fixed cases/denominator, resource/latency thresholds, full checkpoint/recheck budgets, or external authorization is changed. These helpers are not the complete authorized Stage runner.

Observe the owned native sampler while blocking loopback preload, public submit and history requests are pending, and during waits between requests. NativeRuntime preloading requires an attached resource monitor. Dead, invalid, stale (>3 seconds without progress) or threshold-crossing telemetry latches an abort and forbids further model work. Three seconds is a bounded sampler-liveness guard, not a relaxed GPU/RAM threshold or latency limit. Initial sampling progress is tracked before and after native ownership proof.

An observed HTTP request has one owned connection and bounded worker thread. On refusal/interruption shut down only its socket, check cancellation before any late POST after connect, and join it. A still-live HTTP worker is retained and blocks further client requests until actually reaped. Cleanup proof includes absence of these workers. Existing literal-loopback, endpoint/method/body/response/timeout limits remain in force; no redirect, proxy, global interrupt or provider retry is introduced.

Socket disconnect is not model-stop evidence. After an abort, native cleanup revalidates lineage before stopping owned services. Preserve the abort reason and cleanup outcome, never load another model to retry the failed case. New-work authorization expiry cannot invalidate the cleanup reserved by the originating child. Physical GPU release is still a separate raw-sampled obligation; service exit alone cannot satisfy it.

S2 lifecycle identity now requires the live launch handle, listener/wrapper CIM creation ticks, exact executable path and exact native process StartTime ticks. Repeated proof rejects birth changes. Native stop opens a SafeHandle, checks exact StartTime and uses that pinned process object to kill/wait/dispose; it does not issue blind Stop-Process by PID. Do not edit the historical S1 Harness. Record native wrapper absence as well as local launch-handle exit.

Before stopping a listener snapshot up to sixteen descendants/depth eight. Verify their absence afterwards, retain that snapshot across repeated cleanup and refuse to count a later empty port as clean while a known child remains. Do not kill an unproven/foreign descendant. If a service disappeared before a cleanup snapshot, or partial startup lacks native ownership/absence evidence, report unproven cleanup rather than fabricate it. A retained child may therefore keep a native run NO_GO and require further bounded cleanup work; this is not a tested guarantee that all native descendants will exit automatically.

Pure parser checks may parse generated scripts on installed PowerShell, but must execute no script bodies, hardware queries or process stop. Model, browser, GPU and native service behavior remain NOT_RUN until a fresh source/target/sample/port/budget/cleanup-bound program child runs the full parent coordinator. Four categories, security negatives, cancellation/browser/manual export and cumulative regression are still required before independent review and human signoff.
