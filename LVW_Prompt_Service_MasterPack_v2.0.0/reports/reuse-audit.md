# V0-S0 复用审计

审计日期：2026-10-27  
证据性质：静态、只读、部分完成；不是产品验收。  
候选身份：`UNBORN_WORKTREE`，尚不能形成可合并候选或正式 Stage 收据。

## 结论

现有 ComfyUI 与 Prompt Assistant 可以作为 V0 的基础依赖，但 Prompt Assistant 不能原样承担完整的 V0 视频和安全边界。最小实现方向应是：保留其可验证的单图能力，在项目拥有的薄适配层中实现统一合同、手动草稿/导出、路径边界、稳定失败码、清理记录，以及基于 ffmpeg/ffprobe 的有界四帧抽样。

当前结论仅由源码和本机静态信息支持。服务没有启动，节点没有通过 ComfyUI 公共注册表确认，Ollama 模型没有查询，真实媒体没有运行，因此 V0-A01、V0-A02、V0-A09、V0-A10 继续保持 `NOT_RUN`。

## 复用判定

| 对象 | 判定 | 原因与约束 |
|---|---|---|
| ComfyUI 运行时 | 条件复用 | Python、Torch、CUDA 与 4090 可见；仍需冻结实际运行命令、节点注册表和候选版本。 |
| Prompt Assistant `ImageCaptionNode` | 条件复用 | 源码中存在 V3 注册；需通过公共 registry、真实 Ollama 模型和卸载行为验证。 |
| Prompt Assistant `VideoCaptionNode` | 不作为 V0 视频 owner | 它在选择帧前接收完整 IMAGE 批次/完整视频转换结果，且默认 5 帧；不满足 V0 的有界解码和默认 4 帧合同。 |
| Prompt Assistant 视频 info/frame 路由 | 禁止无包装暴露 | 源码接受存在的绝对路径，并可回传绝对路径；与 V0 路径边界和隐私要求冲突。 |
| Prompt Assistant cancel 路由 | 待真实探测 | 路由存在不等于持久终态、模型释放和临时资源清理已经成立。 |
| ffmpeg / ffprobe | 建议复用 | 已安装且适合实现按时间点的有界解码；仍需固定命令、超时、路径白名单和失败码。 |
| Ollama 客户端 | 条件复用 | 客户端存在但服务未运行，Prompt Assistant 当前 Ollama 模型列表为空；禁止把“客户端存在”当作模型可用。 |

## 已识别的 Major 风险

1. 视频 owner 的数据流与冻结合同不一致：先形成完整帧张量，再选帧，无法证明大视频下的内存上界。
2. 视频辅助路由可接受任意存在的绝对路径，并可能把绝对路径写回响应。
3. Prompt Assistant 默认视频帧数为 5，与 V0 默认 4 帧不一致。
4. 当前 Prompt Assistant 的活跃 LLM/VLM 服务是 `zhipu`，而 V0 要求默认离线 Ollama；静态配置不能证明实际路由。
5. 项目仓库没有首个 Git commit；候选、证据和门禁规则暂时不能按 `candidate_sha` 绑定。
6. 目标 ComfyUI 工作树在盘点前已存在大量修改或换行漂移；不得把其当前状态当作干净基线，也不得静默修复。

## 建议的最小实现边界

- 新增项目自有的 V0 薄扩展，拥有统一输入输出 Schema、稳定失败码和运行终态。
- 图片路径可适配并调用经 live registry 验证的 `ImageCaptionNode`，但必须保留 raw 结果且禁止自动改写用户草稿。
- 视频路径由项目扩展校验允许目录后，使用 ffprobe 获取时长，用 ffmpeg 在 4 个确定时间点分别解码单帧；任何时候不持有完整视频帧集。
- 手动模式、编辑区、JSON/TXT 导出不依赖 Ollama，且不得读取 Prompt Assistant 私有配置。
- 所有响应和证据使用路径别名或相对引用，不记录 Cookie、密钥、完整私有绝对路径或原媒体内容。
- 每次运行记录开始/结束、采样点、模型标识、退出码、资源峰值、清理结果和失败码。

## 继续执行所需门槛

在以下条件满足前，S0 不得 PASS：

1. 获得一次有边界的本地运行授权，并明确可启动的服务、可读样本、重试上限和清理责任。
2. 通过 ComfyUI 公共 registry 核对实际 class type 与输入输出，而不是只读源码常量。
3. 查询本地 Ollama 服务和模型；不得下载、升级或改配置，除非另行授权。
4. 使用非私有或明确授权的单图与视频各进行一条真实生产路径探测。
5. 建立 Git 候选身份，并由隔离审查实例复算证据。
