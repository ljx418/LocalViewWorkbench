# 色彩分量注册纠偏（待真实验证）

live12 已完成真实前端、3 次模型动作、3 次 lease 释放和全部清理；独立审查仍为 UM-04 FAIL、9/10、Major1。模型读到了非零注册位移，却声称红框与网格相对位置不变，并猜测无证据的光照/压缩原因。历史 raw 与 NO_GO 不修改。

技术改变：沿用实际源帧的有界灰度注册，额外对 RGB 缩图的三种通用对立色分量 (R-G)/2+128、(G-B)/2+128、(B-R)/2+128 做同一固定面积±10穷举注册。整数截断/钳位遵守 Pillow ImageChops.subtract，结果含 offset、零/最优误差、改善百分数和并列最优数。只报告像素量，不将色分量命名为物体/背景，不将偏移作为真实相机方向，也不向模型提供固定样本答案。

理由：灰度把不同颜色结构混为同一对齐目标；色分量能保留等灰度运动，并允许不同结构得到不同最优偏移。无纹理/窄图明确不可用。现有源 F + 派生 D 单 PNG、一次 Provider、所有帧 SHA/PTS、raw 不变；不改变公开 Schema、固定分母、预测/ctx/资源硬限。内部 presentation=4-colour-alignment，template=1.4.0。视频任务说明压缩去重，强调未知原因而非自相矛盾的静止断言。

局限：仍是128以内缩图、中央窗口、纯平移局部搜索；不支持可靠旋转/缩放/遮挡/场景切分分解。色分量不等于语义区域，量化/缩图/近乎平坦分量可能影响置信度；唯一局部最优不是唯一物理解释。没有新增模型或依赖，不以计量代替实际模型语义验收。
