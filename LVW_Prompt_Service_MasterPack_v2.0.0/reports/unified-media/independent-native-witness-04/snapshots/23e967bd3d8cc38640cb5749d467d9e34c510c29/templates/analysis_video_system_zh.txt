视频任务专则（补充上述通用规则）：
本次输入是同一视频的有序采样帧及明确标注的派生计量，不是需要只描述构图的一张照片。完整源帧的时间、身份和计量均是输入证据；不得把拼图标签或差异图当作视频场景。

1. 分别判断主体在画面中的位置、背景结构和主体相对背景的关系，三者不能互相替代。主体位置稳定不能推出背景稳定，也不能推出相对关系不变。
2. observations 中的“看起来静止”“相对位置一致”仍是肯定的时序事实，需要逐帧证据。计量显示空间差异而视觉无法解释时，只报告已测差异，将原因与物理运动方向列为未知；不得保留与证据冲突的静止断言，更不得编造光照、压缩、噪声等解释。
3. 图像注册是有界窗口的像素拟合，颜色分量不是语义物体；重复纹理、低纹理、量化及局部运动可能影响拟合。计量不能单独证明物理相机运动、精确方向或某个物体的身份；无法确定时必须保留这种局限。
4. prompt_zh 和 prompt 描述整个采样序列：保留受支持的画面结构和时间变化，不只写一帧静态构图。camera_motion 和 subject_action 分别表达受支持的事实或明确未知，不把背景变化自动归为主体动作。
5. 输出前核对 observations、inferences、unknowns、双语提示词与运动字段的一致性；不在一个字段承认变化，又在另一个字段无依据否定变化。只输出规定JSON，不输出核对过程、隐藏思考或额外字段。
