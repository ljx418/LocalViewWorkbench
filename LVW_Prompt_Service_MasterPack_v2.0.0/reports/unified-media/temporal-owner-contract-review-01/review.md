## Conditions that preserve UM04

1. One production Provider request must contain every actual sampled source frame, in actual PTS order with exact frame IDs and hashes; per-frame appearance/pose and shared style must be genuine model observations with real bilingual content. Validate exact ID coverage/cardinality and preserve original per-frame/shared wording. Merely reporting IDs is not proof of accurate visual attention. A four-distinct-image protocol witness proves input visibility only; it cannot replace the original tracking video.
2. Measurements must come from the actual VideoKernel samples, with dimensions, scale, direction convention, bounded search, ties/periodicity and unsupported-cause warnings retained. Changed RGB pixels establish nonidentity; a translation fit establishes only its measured fitting result. Colour channels are not semantic object masks. CPU compilation must never label a channel “background”, assert physical camera movement, infer smooth continuous motion between sparse frames, or prefill the known test answer.
3. Final videoPrompt must communicate supported sampled spatial change, not merely append opaque numbers to a static description. On the original tracking sample, the independent direct-pixel oracle establishes a fixed foreground bbox with grid position changing between samples. Physical camera cause/direction may remain unknown. If the general producer cannot support any useful spatial-change statement beyond “pixels differ; cause unknown”, retain that honest limitation and keep UM04 unresolved; do not redefine the obligation to get a pass. A defensible generic account may describe measured apparent spatial differences with explicit uncertainty and no semantic object naming, but the independent reviewer must still judge whether it faithfully represents this sample and provides useful video reconstruction content.
4. All raw fields remain in quality review, including per-frame statements, shared descriptions, tags, negative, inferences and unknowns. New framing may avoid asking the model for unsupported geometry; it may not shield false temporal assertions that the model actually makes. Any wrong global stillness/unchanged-relative-position claim remains FAIL even if CPU-composed text is correct. No cleaner, parser or compiler may erase/rewrite raw or compensate it into a retrospective pass.

Keep original tracking, same denominator, resource/quality thresholds, no sample substitution and no positive evidence splicing. 6. VideoKernel remains CPU sample/fact owner; Provider remains request/model/lease owner; AnalysisService remains task/cancellation/publication owner; compiler remains deterministic CPU arrangement. No second model call on formatting, no runtime/GPU/browser/network action is authorized by this report.

## Raw quality is a separate retained obligation

PRD business quality says all original results participate. Formal V0-A12 explicitly says “评分原始输出的动作/运镜/局限”; Q01 says “评分原始响应；六模式至少各2图”. These are stronger than merely preserving bytes for audit. This review does not authorize replacing those future raw-response scores with a score of CPU-enhanced output, dropping action/camera dimensions, or counting “unknown” as automatic quality success. A per-frame model task can be evaluated honestly and still fail the existing usefulness criteria. The architecture can proceed internally while that product obligation remains unproven. If the team later wants raw appearance-only output to be deemed sufficient regardless of existing action/camera scoring, that precise change is **NEEDS_PRODUCT_DECISION**, not an owner correction.

The honest distinction is unknown physical cause plus supported sampled facts, versus uncertainty used to avoid describing known observable change. No unsupported physical answer is required. No useful temporal content is guaranteed simply by making every camera/action field unknown. If generic measurement cannot close that gap, retain NO_GO and consider another reviewed implementation route or seek an explicit narrowly stated product change; do not silently reduce the existing oracle.
