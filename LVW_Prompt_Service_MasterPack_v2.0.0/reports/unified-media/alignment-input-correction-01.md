# 有界图像对齐证据路线（离线完成，待新候选真实验证）

触发：live10同一四源帧+相邻残差的真实请求已执行并完整清理，但原始模型inference仍称grid与红框空间恒定并猜噪声/压缩；旧失败不改写。派生残差揭示变化，却未提供位置变化的可复算几何量。

新路线不再只改提示词：对所有实际decoded.frames作通用128×128以内灰度图像注册；每对帧以同一中央窗口，在±10像素范围穷举next对齐previous的偏移，计算固定面积绝对灰度误差。输出分析尺寸/搜索范围/最佳对齐偏移/零偏移与最佳误差/改善比例/相等最优数；无纹理与过窄明确不可用。

这是图像对齐测量而非物理相机运动或物体分类。固定中央窗口可能忽略边缘，缩小/灰度会丢失细节和色差，重复纹理可产生搜索范围以外alias；即使只有一个局部最优也不保证真实位移或原因唯一。模型仍必须保留未知，不能被喂给固定视频名称、预期运动标签或样本答案。
