# 资源清理按钮：使用与证据

1. 关闭旧 LVW 启动窗口，再双击原启动图标；刷新网页不会更新已运行的旧 Python 后端。
2. 在页面顶部“本地后端服务”点击“资源清理”。有分析正在运行时先取消，等待资源释放；按钮在切换期间禁用。
3. 根据实际结果继续：`released` 是已核实目标模型卸载；`noop` 是没有可清理目标；`blocked` 是外部/未知归属；`unknown` 是释放尚未确认。后两者都不是清理成功。
4. “再次检查服务”重新读取后端状态。下次分析按需装载模型；人工稿与导出始终保留。

该动作是固定后端脚本逻辑，不执行用户输入的命令，不删除文件或清空数据库，不重启驱动，不结束其他软件。没有 LVW lease 且服务由外部启动时，不会冒认占用归属。Windows 桌面、浏览器或其他软件占用不能由此按钮全部释放；WSL `/proc/meminfo` 数值仅代表运行环境可用内存。
