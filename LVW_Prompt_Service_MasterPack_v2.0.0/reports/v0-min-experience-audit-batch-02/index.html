这轮真正说明了什么

系统已经能跨摄影、绘画和插画生成结构化英文反推提示词，但“看见了什么”和“人物正在做什么”不是同一个难度。后者需要额外的语义质量控制，不能只依赖 Schema 和非空检查。

稳定能力

  • 主体、颜色、材质、空间关系与光线。
  • 多数场景能把地点、物种等未知事实留空。
  • 六次均完成本机路径、模型卸载和资源清理。

下一改进点

  • 增加人物动作/表情的人工确认提示。
  • 对破损词和 tag 拼写增加确定性检查。
  • 补齐中文与 negative 输出。
