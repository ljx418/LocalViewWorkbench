## 无命令启动入口

优先双击根目录 `启动LVW.lnk` 或 `LVW.exe`。原生Windows启动窗口提供图片、视频、验收指南入口；视频按钮自动完成下述临时目录、扩展复制、环境设置及服务启动，确认LVW视频节点注册后自动打开网页。无需手动粘贴PowerShell。视频工作流JSON可通过“定位视频工作流文件”按钮找到并拖入Comfy页面。下文命令保留作为高级诊断备用。

启动窗口本身不占用模型；视频会话文件保留以保护导出内容，关闭启动窗口不会自动杀服务。详见[启动器说明](../launcher/README.md)。

## 图片：独立工作台

1. 在资源管理器打开 `C:\workSpace\videoWorkLine\LocalViewWorkbench\LVW_Prompt_Service_MasterPack_v2.0.0`，双击 `START_LVW.cmd`，保留窗口。
2. 浏览器通常自动打开 `http://127.0.0.1:18765`；如果被占用，启动器选择18766–18775，以实际窗口为准。
3. 查看“本地后端服务”。Ollama未运行时点击“启动模型服务”；确认本机已有 `gemma4:26b`。缺模型只报告，不自动下载。
4. 上传JPEG/PNG/WebP（≤20MiB、4000万像素），选择表达/内容预设和附加要求，点击“分析图片”。
5. 查看机器建议，点击“采纳到人工稿”；有旧稿时确认替换。修改后导出TXT/JSON并回读。工作稿只在当前页面会话中，离开前导出。

这是已签R1a单图切片，目前不支持视频。不能把图片页面当成S2视频入口。遇到MODEL_UNAVAILABLE先看服务面板；runtime/status 404时检查是否连接旧服务或错误端口。重置/关闭只作用于本轮LVW启动的Ollama，外部服务不强制终止。

## 视频：临时隔离ComfyUI

本机既有安装为 `C:\ComfyUI-aki-v2`。2026-11-08只读检查时，其常驻custom_nodes中没有lvw_v0_bridge。因此，不应直接告诉用户“打开普通ComfyUI并拖图即可”。

1. 先从图片工作台启动本轮Ollama，供本机视频流程复用；不必先做一次图片分析。
2. 新开Windows PowerShell，把HTML“启动视频工作流”中的完整命令粘贴执行；同一命令的文字副本在[video-start-command.txt](../reports/manual-acceptance-guide-2026-11-08/video-start-command.txt)。
3. 命令使用现有Python、FFmpeg与PyAV，将24份扩展文件复制到新的 `%TEMP%\lvw-s2-experience-<唯一编号>`；不复制权重、不覆盖常驻ComfyUI、不修改永久环境或执行策略、不自动打开浏览器。8191占用时提示停止，不误杀进程。
4. 看到启动地址后手动打开 `http://127.0.0.1:8191`。保留PowerShell窗口。
5. 在ComfyUI导入项目内 `LVW_V0_RuntimePatch\workflows\video_reverse_prompt_v0.ui.json`。确认LVW节点没有缺失。
6. 节点中选择并上传MP4/MOV，等待上传完成，再点ComfyUI“运行”。视频≤256MiB、≤60秒、源单帧≤8294400像素；默认观察四个不同时间点，极短片可少帧并提示，不复制帧。
7. 依次体验：人工稿先写字→分析→查看原始响应/建议→确认原稿未变→显式采纳→编辑→复制/导出→新分析期间取消→确认旧稿保留。
8. 只停止你自己启动的Ollama，保持ComfyUI开启，体验视频人工稿编辑与导出。若Ollama标为外部服务，不能为了验收终止不明进程；记录实际情况。

该命令的完整语法及临时复制前缀已在本机检查，24文件逐项SHA一致，测试临时根已删除；本次指南任务没有实际启动产品服务或模型。正式服务/模型机器验证见full08原始证据，不能把本次语法检查当作新一次真实识别。
