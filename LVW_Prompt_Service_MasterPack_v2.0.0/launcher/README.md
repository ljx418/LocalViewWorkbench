# LVW 双击启动入口

双击桌面“LVW提示词工作台”、根目录 **启动LVW.lnk** 或 **LVW.exe**。点击“打开图文视频工作台”，同一 React 页面支持图片与短视频，无需打开 ComfyUI 或导入节点图。

启动器复用 START_LVW.cmd，在18765–18775选择空闲端口；只复用构建身份一致的服务。运行依赖本机既有 Windows .NET Framework、WSL Ubuntu-24.04、Python依赖、FFmpeg/FFprobe和Ollama。不下载软件或权重，不改永久配置。

在网页服务面板点击“启动模型服务”，待模型可用后选择图片或视频并分析。重置/关闭只管理本轮启动、拥有原始Windows进程句柄的Ollama；外部服务不强制终止。推理前核对资源，不证明释放时不能继续新分析。

另两个按钮分别打开本轮验收报告、人工验收指南。历史Comfy验收记录保留在带“S2历史”的HTML中，不是当前视频入口。

先导出人工稿，再关闭网页中的模型服务，最后在运行服务窗口按Ctrl+C。关闭启动器自身不会停止服务。临时输入与解码文件只属于本次会话，退出时清理；不要把它当作资产库。页面刷新前也应导出，完整SQLite修订持久化仍待后续R1。

源码Launcher.cs与图标LVW.ico在本目录；开发构建见reports/unified-media/build_launcher.py。现成LVW.exe可直接运行，移动目录后快捷方式可能失效，可双击新目录中的LVW.exe。
