# LVW 双击启动入口

桌面已创建“LVW提示词工作台”快捷方式。也可在项目根目录双击 **启动LVW.lnk** 或 **LVW.exe**。无需安装、管理员权限、修改执行策略或输入命令。图标和源码随项目保存；快捷方式绑定当前项目绝对路径，移动项目后可直接使用同目录LVW.exe。

- **打开图片反推工作台**：复用START_LVW.cmd及其端口检查/18765–18775选择。浏览器打开后，在服务面板启动本地模型，再上传图片。重复启动复用现有兼容图片服务。
- **启动视频反推工作流**：复用已有C:\ComfyUI-aki-v2 Python/ComfyUI/FFmpeg/PyAV；复制薄扩展到本轮唯一临时目录，隔离user/input/output/cache，绑定127.0.0.1:8191。轮询确认LVWVideoPromptOwner已注册才自动打开网页；端口被占或缺依赖会提示，不终止未知进程、不下载。视频模型需先通过图片工作台启动。
- **定位视频工作流文件**：资源管理器选中真实video_reverse_prompt_v0.ui.json；将文件拖入视频页面，上传视频后点运行。
- **查看本轮视频文件**：打开本轮会话目录，供查看输出和诊断。目录不会自动删除，避免丢失用户导出。
- **打开人工验收指南**：打开离线HTML，记录体验和问题；不会自动签署。

先导出人工稿，再在对应图片/视频服务窗口按Ctrl+C停止。关闭启动器本身不会终止服务或外部Ollama。模型服务仍通过图片页面的服务面板管理；只管理本轮拥有的模型进程。确认视频停止、所需文件已另存后，才可删除“查看本轮视频文件”打开的那个lvw-s2-desktop-唯一编号目录。

本启动器只增加入口封装，不改产品HTTP接口、人工稿、模型提示词、固定分母或Stage门限。S2原产品机器验收候选保持719c745…；启动器有单独定向验证收据，不将旧产品验收冒充新启动器的人工验收。

源码Launcher.cs、图标LVW.ico及开发构建脚本build.ps1均在本目录。用户只需运行现成的根目录LVW.exe，不需要执行构建脚本。依赖Windows已有.NET Framework 4.x、项目原有WSL/Python和本机ComfyUI；不包含权重。
